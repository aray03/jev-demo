# Intro to Jev: slide deck

A Reveal.js deck introducing TypeSafe's Jev for class.

- **Live:** https://aray03.github.io/jev-demo/
- **Run locally:** `python -m http.server`, then open http://localhost:8000
- **Keys:** arrow keys to move, `S` for speaker notes, `F` for fullscreen, `Esc` for the overview

Put screenshots in `images/recycling.png` and `images/pokemon.png`.
Prices and chart assumptions are in `js/charts.js`.
